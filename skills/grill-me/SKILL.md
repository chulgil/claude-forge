# Grill Me — 끈질긴 인터뷰

## 목적

아이디어나 설계에 대해 LLM과 **공유된 이해(shared understanding)**에 도달하기 위해, AI가 사용자를 끈질기게 인터뷰하도록 강제한다. Claude Code의 Plan 모드가 너무 빨리 계획을 내놓는 문제를 해결한다.

## 핵심 지침

공유된 이해에 도달할 때까지 이 계획의 모든 측면에 대해 나를 끈질기게 인터뷰하세요.
디자인 트리의 각 가지를 따라 내려가면서 결정 사항의 의존성을 하나씩 해결하세요.
코드베이스를 탐색해서 답할 수 있는 질문이라면 직접 코드베이스를 탐색하세요.

## 디자인 트리란

Frederick P. Brooks의 "Design of Design"에서 유래한 개념. 설계 시 트리의 모든 가지를 끝까지 탐색하여 결정 사항을 완전히 파악하는 방법론.

```
기능 설계
├── 선택지 A → 세부 결정 1 → 하위 결정 ...
│               └── 세부 결정 2 → ...
└── 선택지 B → 세부 결정 3 → ...
```

## 사용 시점

- 새로운 기능을 설계할 때
- 복잡한 리팩토링을 계획할 때
- 아키텍처 결정이 필요할 때
- Plan 모드가 너무 성급하게 느껴질 때

## 기대 결과

- 16~40개의 심층 질문
- 30~45분 소요 (복잡한 기능의 경우)
- 모든 파급 효과가 파악된 상태에서 구현 시작 가능

## 주의사항

- 스킬이 길어야 임팩트가 있는 게 아니다. 적절한 시점에 적절한 단어("의존성을 해결한다")가 핵심
- 인터뷰가 끝나기 전에 계획/문서 작성으로 넘어가지 않도록 주의
